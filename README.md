# 🎂 Sorpresa de cumpleaños

Página web interactiva (un solo archivo, `index.html`). No necesita instalar nada.

## Cómo publicarla en GitHub Pages (gratis)

1. Crea una cuenta en https://github.com si no tienes.
2. Pulsa **New repository** (botón verde arriba a la derecha).
   - Ponle un nombre difícil de adivinar, por ejemplo `sorpresa-x7k2q`.
   - Márcalo como **Public** (en el plan gratuito, GitHub Pages lo necesita).
   - Pulsa **Create repository**.
3. En el repositorio nuevo pulsa **uploading an existing file** (o **Add file → Upload files**).
4. Arrastra `index.html` (y `.nojekyll` si quieres) y pulsa **Commit changes**.
5. Ve a **Settings → Pages**.
   - En **Source** elige **Deploy from a branch**.
   - En **Branch** elige `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera 1–2 minutos y recarga. Arriba aparecerá tu enlace:
   `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`
7. Copia el enlace y envíalo por WhatsApp. Para el código QR, pega el enlace en cualquier generador de QR gratuito.

## Para probarla sin esperar a la fecha

Añade `#probar` al final del enlace. Ejemplo:
`https://TU-USUARIO.github.io/NOMBRE/#probar`
Con eso el sobre se abre aunque no sea todavía el 21/10/2026. Sin esa parte, el sobre está bloqueado hasta esa fecha.

## Cosas que debes saber

- Al ser un repositorio público, cualquiera que encuentre la dirección podría ver el código, incluidas las respuestas correctas. Por eso conviene un nombre difícil de adivinar.
- El bloqueo por fecha usa el reloj del móvil de quien lo abre.
- Lo que ella escribe en la pregunta abierta se queda solo en su móvil; no te llega a ti.
- Para cambiar textos, preguntas o respuestas, edita `index.html` en GitHub (icono del lápiz) o pídeselo a Claude y sube el archivo nuevo.
